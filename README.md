# Информационная система управления сервисом каршеринга

Учебный групповой проект по дисциплине «Проектирование ПО» (3 курс, 1 семестр).

**О проекте.** Каршеринг как цифровая надстройка над действующей компанией проката автомобилей в Симферополе: клиент проходит верификацию, подписывает договор, вносит обеспечительную сумму и открывает автомобиль в мобильном приложении, без визита в офис и бумажных документов. Подробнее в [Vision & Scope](docs/01-vision-and-scope.md).

```

├── 01-vision-and-scope.md          задание 1

├── 03-activity-diagrams/           задание 3 (3 диаграммы деятельности)
├── 04-domain/                      задание 4 (глоссарий, бизнес-правила, сущности)

├── 06-class-diagram/               задание 6 (диаграмма классов)
└── 07-state-diagrams/              задание 7 (5 диаграмм состояний)
journal/JOURNAL.md                  журнал работы команды
```

В папках с диаграммами лежат PNG для просмотра, SVG для редактирования (открывается в draw.io и Inkscape) и папка `src/` с исходниками.

## Как связаны документы

Vision & Scope задаёт цели (BG) → диаграмма прецедентов даёт акторов и прецеденты (UC) → диаграммы деятельности и бизнес-правила (БП) раскрывают процессы → спецификация (US, FR, AC) опирается на UC и БП → диаграмма классов и диаграммы состояний описывают структуру и жизненный цикл сущностей. Таблица трассируемости находится в конце [спецификации](docs/05-requirements/user-stories.md).

## Правила работы с репозиторием

1. Все материалы хранятся только здесь, без разрозненных локальных файлов.
2. Диаграммы: исходник (в `src/`) и экспорт в `.png` и `.svg`.
3. Каждая работа над заданием идёт в своей ветке (`task-05-requirements`), затем Pull Request в `main`.
4. Формат коммитов: `task-05: добавил критерии приёмки для US-04`.
5. После каждой активности участник дописывает строку в `journal/JOURNAL.md`.
6. Если меняете бизнес-правило, проверьте все ссылки на его номер (`БП-xx`) в диаграммах и спецификации.

## Как перерисовать диаграммы

| Диаграмма | Команда (из папки `src/`) | Нужно установить |
|---|---|---|
| Прецеденты | `python3 gen_usecase.py` | `pip install matplotlib` |
| Деятельность | `python3 ad_registration.py`, `ad_rental.py`, `ad_incident.py` | `pip install matplotlib` |
| Классы | `java -jar ~/plantuml.jar -tpng class-diagram.puml` | PlantUML, Java |
| Состояния | `python3 gen_states.py` | Graphviz (`dot`) |

Результат появляется в папке `src/`, его нужно переместить на уровень выше. Для шрифта используется Liberation Sans (при его отсутствии подставится DejaVu Sans).
