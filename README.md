## Правила работы с репозиторием

1. Все материалы хранятся только здесь, без разрозненных локальных файлов.
2. Диаграммы: исходник (`.puml`, `.mmd` или `.drawio`) + экспорт в `.png`.
3. Каждая работа над заданием идёт в своей ветке (`task-02-usecase`), затем Pull Request в `main`.
4. Формат коммитов: `task-01: добавил раздел «Границы»`.
5. После каждой активности участник дописывает строку в `journal/JOURNAL.md`.
