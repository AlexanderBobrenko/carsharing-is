## Правила работы с репозиторием

1. Диаграммы: исходник (`.puml`, `.mmd` или `.drawio`) + экспорт в `.png`.
2. Каждая работа над заданием идёт в своей ветке (`task-02-usecase`), затем Pull Request в `main`.
3. Формат коммитов: `task-01: добавил раздел «Границы»`.
4. После каждой активности участник дописывает строку в `journal/JOURNAL.md`.
